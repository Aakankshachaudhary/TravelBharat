# TravelBharat Client

React + Vite frontend for TravelBharat.

## Main user areas

- Home
- Explore States
- State details
- Destination details
- Search and discovery
- About
- Admin login
- Protected admin dashboard

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

Set `VITE_API_BASE_URL` in `client/.env` when the API is not running at the default local URL.
